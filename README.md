## Solitaire Project — CS 449

This project will develop a Solitaire game using Python.
Sprint 0 includes a basic card deck, unit tests, and a GUI
for selecting game settings. The full game is not implemented yet.
## Tools

- Language: Python 3
- GUI library: Tkinter
- IDE: Visual Studio Code
- Testing framework: unittest
- Style guide: Google Python Style Guide

## 📁 Project Structure

```text
deck.py           # Creates the deck and deals cards
test_deck.py      # Unit tests for the deck
solitaire_gui.py  # Solitaire settings window
```
